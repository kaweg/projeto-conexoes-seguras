## 🎯 Objetivo do Projeto
Este repositório compreende a **Parte 1** do projeto prático semestral corporativo. O foco principal é desenvolver a documentação técnica consolidada e realizar a implementação prática de uma **Prova de Conceito (PoC)** para os principais mecanismos de segurança e infraestrutura de redes corporativas.

## 📂 Estrutura dos Módulos Implementados

Cada diretório abaixo possui um arquivo de documentação dedicado contendo a fundamentação teórica solicitada e as evidências práticas estruturadas sob o padrão: `Ferramenta usada ➔ Passo a Passo ➔ Resultado ➔ Explicação Técnica`.

<details open>
  <summary><b>📐 Clique para expandir/recolher o Sumário dos Módulos</b></summary>
  <br />
  
  <ul>
    <li>
      <b><a href="./modulo1-sniffing/">📂 Módulo 1: Sniffing e Interceptação (Camada 2 e 3)</a></b>
      <br />Análise técnica sobre o Modo Promíscuo, alteração de comportamento da NIC e interceptação de pacotes de infraestrutura.
    </li>
    <br />
    <li>
      <b><a href="./modulo2-tls/">📂 Módulo 2: Criptografia e Handshake (A base do TLS)</a></b>
      <br />Fundamentos sobre criptografia híbrida. Uso de algoritmos assimétricos para a troca de chaves e simétricos (AES) para alta performance em tráfego de dados.
    </li>
    <br />
    <li>
      <b><a href="./modulo3-sessao/">📂 Módulo 3: Segurança na Camada de Aplicação (Desenvolvimento)</a></b>

    </li>
    <br />
    <li>
      <b><a href="./modulo4-vpn/evidencias">📂 Módulo 4: VPN (Virtual Private Network)</a></b>
      <br />Estudo de caso e PoC cobrindo arquitetura de tunelamento e comparação estrutural entre os protocolos OpenVPN e IPsec.
