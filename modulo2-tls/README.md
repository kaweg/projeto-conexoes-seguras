<h1>Criptografia Híbrida: Por que o HTTPS não utiliza apenas criptografia assimétrica (RSA/ECC) para todo o tráfego? O conceito de usar criptografia assimétrica para a troca de chaves e simétrica (AES) para a transferência de dados.</h1>

<p>O protocolo HTTPS não utiliza criptografia assimétrica para todo o tráfego devido a limitações severas de desempenho e eficiência computacional. Os algoritmos assimétricos (como RSA e ECC) baseiam-se em problemas matemáticos complexos envolvendo a fatoração de números primos gigantescos ou curvas elípticas. Consequentemente, o processo de cifrar e decifrar grandes volumes de dados (como imagens, vídeos e arquivos de páginas web) usando chaves assimétricas exigiria um uso massivo de processamento (CPU) tanto do servidor quanto do cliente, tornando a navegação web extremamente lenta e inviabilizando a escalabilidade de servidores corporativos.  Para solucionar este gargalo, o HTTPS adota a Criptografia Híbrida, que combina o melhor dos dois mundos: a segurança da criptografia assimétrica com a velocidade da criptografia simétrica. O funcionamento divide-se em duas fases distintas:  1. Fase Assimétrica (Troca de Chaves / Handshake TLS): No início da conexão, o cliente solicita a chave pública do servidor. O servidor envia seu certificado digital contendo sua chave pública. O cliente gera uma chave aleatória temporária, chamada Chave de Sessão, e a criptografa utilizando a chave pública do servidor. Essa mensagem trancada é enviada ao servidor, que utiliza sua chave privada correspondente para descriptografá-la. Como apenas o servidor possui a chave privada, a troca da chave de sessão ocorre de forma 100% segura, mesmo em canais públicos.
2. Fase Simétrica (Transferência de Dados): Uma vez que ambas as partes compartilham de forma segura a mesma Chave de Sessão, o algoritmo assimétrico é interrompido. Toda a comunicação subsequente e a transferência de dados passam a ser cifradas por algoritmos simétricos de alta performance, como o AES. A criptografia simétrica realiza operações de substituição e permutação de bits em blocos, o que consome uma fração mínima de hardware, permitindo uma transferência de dados veloz e segura.</p>
