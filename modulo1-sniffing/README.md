<h1> Modo Promíscuo e Captura de Pacotes: O que é e como o modo promíscuo altera o comportamento do controlador de interface de rede (NIC). </h1>

<p>Em uma operação padrão de rede (Modo Não-Promíscuo), o Controlador de Interface de Rede (NIC - Network Interface Card) atua como um filtro baseado em hardware na Camada 2 (Enlace) do modelo OSI. Quando os quadros de dados trafegam pelo meio físico (seja um cabo de cobre ou ondas de rádio), a NIC examina o cabeçalho de cada quadro para verificar o Endereço MAC de destino. Se o MAC de destino não corresponder ao endereço físico da própria placa, e não for um endereço de broadcast ou multicast autorizado, a NIC descarta o quadro imediatamente por hardware. Isso impede que o Sistema Operacional e a CPU gastem ciclos de processamento com tráfego alheio. Quando a NIC é configurada para operar em Modo Promíscuo, esse filtro de hardware é desativado. A partir deste momento, a placa de rede passa a capturar e encaminhar para a pilha de protocolos do Sistema Operacional todos os quadros que transitam pelo meio físico compartilhado, independentemente do endereço MAC contido no cabeçalho de destino.  Em ambientes de análise de rede ou auditorias de segurança (utilizando ferramentas como o Wireshark), o modo promíscuo é fundamental para o Sniffing, pois permite monitorar a integridade do tráfego local. Contudo, em cenários de ataque, se um agente malicioso obtiver acesso físico ou lógico a um segmento da rede, ele utilizará o modo promíscuo para interceptar dados confidenciais que estejam trafegando sem criptografia nas camadas superiores.</p>
